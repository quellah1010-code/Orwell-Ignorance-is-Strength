Orwell: Ignorance is Strength 中文界面测试包 0.3

内容
欢迎页、创建档案、档案选项和设置页：130 处主菜单场景文本、39 条程序动态文字。
新增能力测试的 63 处场景文字、34 条提交后的答案、20 条书签文字和 7 个任务栏标题。
姓名输入框调整了标签、文本区域和占位文字的对齐、内边距及字号，需实机确认。
保留 0.1 的 14 条开场介绍和任务译文，并扩充中文备用字库。
制作人员名单正文及游戏剧情尚未完整汉化。本包不是全游戏汉化。
游戏名 ORWELL 作为标识保留，副标题译为“无知即力量”。

安装前
完全退出游戏。必须备份以下四个原版文件，保留各自目录结构：
  Ignorance_Data/resources.assets
  Ignorance_Data/level1
  Ignorance_Data/level4
  Ignorance_Data/Managed/Assembly-CSharp.dll
如果已安装 0.1 或 0.2，先恢复之前修改过的文件，或用 Steam 验证完整性恢复原版；不要把补丁文件当原版。

安装
解压 orwell-zh-menu-0.3.zip，将包内 Ignorance_Data 的四个文件复制到游戏对应目录。
同意替换对应文件，但不要删除整个 Managed 或 Ignorance_Data 文件夹。
启动游戏并保持英文语言设置。
首页应显示“欢迎”“你已获准加入‘奥威尔’”“请创建个人档案”“空白档案”“创建”。
已有存档时首页内容可能不同；已有的自定义档案名称不会被翻译或更改。

检查
检查首页及设置页是否有方框、缺字、文字倒置或遮挡。
点击“创建”，查看头像、姓名、下一步、条款等文字能否正常显示和点击。
检查姓名输入、占位文字、边框和取消返回是否正常。不要为测试而删除已有档案。
进入能力测试，检查说明、各题文字、拖拽选项、左侧答案和结果提示。
部分任务有互斥选项，需检查原有选择限制和提交行为是否正常。
带有 {0} 等占位符的提示应显示实际数值。
长段隐私说明和条款需检查换行；请反馈异常截图。
代码和资源回读验证通过不等于实机显示验证，当前尚未完成 Windows 游戏内验证。

还原
退出游戏，将备份的上述四个原版文件全部放回对应位置。
只还原 resources.assets 会留下另外三处修改，不能算完整卸载。

字体与构建
字库采用 Noto Sans CJK SC，SIL OFL 1.1 许可见 FONT-LICENSE.txt。
程序静态修改 Assembly-CSharp.dll 中选定的用户字符串，不执行原版程序集；
其余程序集字节、方法代码和字符串引用位置保持不变。
生成文件含有本地游戏资源，请勿提交到公开仓库或公开分发。
