Orwell: Ignorance is Strength 中文显示测试包 v0.1

这是用于验证汉化技术路线的小样，不是完整汉化。
内容：能力测试结束后安普尔福德开场介绍的 11 条对白（含不同分支），以及 3 条早期任务，共 14 条文本；另加入了中文备用字库。
主菜单、网页、邮件和其他对白尚未翻译。人名与术语为暂定译法。

适用对象
仅用于你本次上传文件对应的 Windows Steam 版本。
原 resources.assets 的 SHA-256：
1bc553fdc10358d2a4f78de1e2079a61ee46dc993636403dcfbc7b052b607b78

安装
1. 完全退出游戏。
2. 在 Steam 中右键游戏，选择“管理 → 浏览本地文件”，进入 Ignorance_Data。
3. 先把原 resources.assets 复制到游戏目录外，作为备份；保存好它。
4. 将本包 Ignorance_Data 里的 resources.assets 复制到游戏同名目录，替换原文件。
5. 启动游戏，使用英文语言设置。用测试存档进入能力测试结束后的开场介绍。

检查
- 介绍中的“我叫安普尔福德……”应显示中文；不同能力测试回答会触发不同的首句。
- 检查是否出现方框、缺字、倒置、遮挡或异常换行。
- 检查点击继续、阅读后续对话和查看早期任务是否正常。
- “{CHAR_BAYTE}”等内部标记应由游戏替换成人物名，而非原样显示。
- 将结果和截图发回，以便调整字体、排版和回填方式。

还原
退出游戏，将第 3 步保留的原 resources.assets 复制回 Ignorance_Data，替换测试文件。
本包只替换这一个资源文件。

验证范围
已验证：14 条译文重新读取一致；其他原资源对象的内容未变（TMP Settings 的备用字体列表除外）；新增字库及材质引用有效；字形贴图编码后重新解码完全一致。
尚未验证：Windows 游戏启动、实际渲染、换行和交互。云端无法运行你本地的完整游戏。
